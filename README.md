# ML Class

This repository contains Jupyter Notebook (`.ipynb`) files with exercises, assignments, and in-class tasks related to Machine Learning and Deep Learning.

## Overview

The notebooks in this repository collect practical work completed during ML classes. They are meant to serve as a reference for concepts covered in class, implementation examples, and experimentation with different machine learning methods.

## Repository Structure

- `*.ipynb` — Jupyter notebooks with class exercises, tasks, and experiments
- Python code for model implementation, training, and evaluation
- Markdown explanations, observations, and notes inside the notebooks

## Topics Covered

The repository may include notebooks on topics such as:

- Data preprocessing and feature engineering
- Supervised learning
- Unsupervised learning
- Regression and classification
- Model evaluation and validation
- Decision trees and ensemble methods
- Support vector machines
- Neural networks
- Deep learning basics
- Training and tuning deep learning models
- Optimization and loss functions
- Convolutional neural networks (CNNs)
- Sequence models and recurrent neural networks (RNNs), depending on course content

## Requirements

To run the notebooks, you typically need:

- Python 3.x
- Jupyter Notebook or JupyterLab
- Common libraries such as `numpy`, `pandas`, `matplotlib`, `seaborn`, `scikit-learn`, `tensorflow`, `keras`, or `torch`

If a `requirements.txt` file is included, install the dependencies with:

```bash
pip install -r requirements.txt
```

## Usage

1. Clone the repository:

```bash
git clone https://github.com/Showcas/ML_Class.git
```

2. Change into the repository folder:

```bash
cd ML_Class
```

3. Start Jupyter:

```bash
jupyter notebook
```

4. Open a notebook and run the cells step by step.

## Purpose

This repository is intended for educational use and documentation of coursework. The notebooks may contain exploratory implementations created during class, so the focus is often on understanding concepts rather than building production-ready systems.
